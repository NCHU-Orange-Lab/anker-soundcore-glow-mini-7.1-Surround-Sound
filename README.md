# Soundcore Desk

用來控制 **soundcore Glow Mini（型號 A3136）** 藍牙喇叭的 Windows 桌面程式，介面為繁體中文。

- 每顆連上電腦的喇叭各一張卡片：各自調音量、靜音，查看電量、充電狀態、韌體與序號，開關 PartyCast。
- 把兩組 TWS 喇叭組成**前後 4 聲道環繞**：電腦播放的 5.1／7.1 聲音拆成前左、前右、後左、後右。一般立體聲音樂也能用「擴展環繞」補出後方的空間感。
- 提供「環繞同步測試」，用滴答聲對齊兩組喇叭。

> 這是獨立開發的工具，**不是** Anker 官方應用程式。程式只使用 Windows 內建元件，不連網路，也不需要系統管理員權限。

目前版本：**v1.13**

## 功能一覽

| 功能 | 說明 |
|---|---|
| 每顆喇叭一張卡片 | 音量滑桿、±5%、25／50／75%、靜音，只作用在那一顆 |
| 電量 | Windows 藍牙服務回報的百分比與回報時間 |
| 充電狀態 | 直接向 Glow Mini 專用通道查詢「正在充電／未在充電」 |
| 韌體與序號 | 從喇叭的狀態封包讀出 |
| PartyCast | 開啟／關閉，並向喇叭確認結果；顯示曾一起 PartyCast 的喇叭上次讀到的資料 |
| 4 聲道環繞 | 以虛擬音效裝置（VB-CABLE）為來源，拆成前後兩組送到兩組 TWS 主喇叭 |
| 擴展環繞 | 一般立體聲內容時，把左右聲道之間的空間感分離出來送到後方，人聲留在前方 |
| 環繞同步測試 | 兩顆喇叭同時播放高低音滴答聲，對齊延遲並記錄長時間漂移 |
| 通知區域 | 收到右下角繼續運作；選單可調全部喇叭音量、靜音 |
| 快捷鍵 | `Ctrl + ↑ / ↓` 全部喇叭 ±5%，`Ctrl + M` 全部靜音／取消靜音 |

### 執行環境

| 項目 | 需求 | 備註 |
|---|---|---|
| 作業系統 | Windows 10 或 Windows 11（64 位元） | |
| .NET Framework | 4.8 以上 | Windows 10 1903 以後與 Windows 11 已內建，通常不用另外安裝 |
| 藍牙 | 電腦內建藍牙或 USB 藍牙接收器 | 要同時接兩組喇叭，建議使用真正的藍牙 5.x 接收器，見[疑難排解](#聲音斷斷續續) |

確認 .NET Framework 版本（數字 **528040 以上**代表 4.8 以上）：

```powershell
(Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full').Release
```

### 程式用到的元件

**沒有任何第三方套件**：不需要 NuGet、npm、Python、Node.js 或 Visual Studio。用到的都是 Windows 與 .NET Framework 4.8 內建的元件：

| 元件 | 用途 |
|---|---|
| WPF | 視窗介面（XAML 內嵌在 EXE 中） |

| Core Audio：WASAPI（`IAudioClient`、loopback 擷取、render） | 4 聲道環繞與同步測試的音訊處理 |
| `bthprops.cpl`（Bluetooth API） | 取得已配對藍牙裝置的名稱、位址與連線狀態 |

| Winsock 藍牙 RFCOMM（`AF_BTH`） | 與 Glow Mini 專用服務通訊：充電、韌體、PartyCast |

## 安裝

本程式不需要安裝程式，只有一個 EXE。

### 方式一：下載 Releases（最簡單）

1. 到 [Releases 頁面](https://github.com/NCHU-Orange-Lab/anker-soundcore-glow-mini-7.1-Surround-Sound/releases)下載最新版的 `SoundcoreDesk-v版本-win-x64.zip`。
2. 解壓縮到任何資料夾，例如 `C:\Tools\SoundcoreDesk`。
3. 執行 `SoundcoreDesk.exe`。

執行檔沒有數位簽章，第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，按「其他資訊 → 仍要執行」即可。Releases 頁面附有 SHA-256，可以用下面的指令核對下載的檔案：

```powershell
Get-FileHash .\SoundcoreDesk.exe -Algorithm SHA256
```

### 方式二：從原始碼建置

1. 下載原始碼：

   ```powershell
   git clone https://github.com/NCHU-Orange-Lab/anker-soundcore-glow-mini-7.1-Surround-Sound.git
   cd anker-soundcore-glow-mini-7.1-Surround-Sound
   ```

   沒有安裝 git 的話，也可以在 GitHub 頁面按「Code → Download ZIP」，下載後解壓縮。

2. 建置（約 10 秒，會產生 `dist\SoundcoreDesk.exe`）：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
   ```

3. 雙擊專案資料夾中的 **`Launch.cmd`**，或直接執行 `dist\SoundcoreDesk.exe`。

建置出的 `SoundcoreDesk.exe` 已內嵌介面與圖示，可以單獨複製到其他電腦使用。

### 開機自動啟動（選用）

按 `Win + R`，輸入 `shell:startup` 開啟啟動資料夾，把 `SoundcoreDesk.exe` 的捷徑放進去。

### 安裝 VB-CABLE（只有 4 聲道環繞需要）

1. 到 VB-Audio 官網下載 **VB-CABLE Driver Pack**：<https://vb-audio.com/Cable/>
2. 解壓縮後，對 `VBCABLE_Setup_x64.exe` 按右鍵「**以系統管理員身分執行**」，再按「Install Driver」。
3. **重新開機**。
4. 完成後，Windows 的聲音設定會多出播放裝置「**CABLE Input**」與錄音裝置「CABLE Output」。新版驅動程式可能還會多一個「CABLE In 16ch」，本程式使用 **CABLE Input** 即可。

## 使用說明

### 首頁：我的喇叭

每顆**已連線**的 Glow Mini 各有一張卡片，卡片上的所有操作只作用在那一顆：

| 位置 | 內容 |
|---|---|
| 標題列 | 連線狀態；名稱後面的 `D2:BB` 等是藍牙位址末兩碼，用來分辨同名喇叭。若已在環繞頁指定，會標示「環繞前方」或「環繞後方」 |
| 藍牙位址 | 完整位址。滑鼠移上去可看到 Windows 音訊裝置的代號 |
| 韌體與序號 | 從喇叭狀態封包讀出 |
| 電量 | Windows 回報的百分比與回報時間 |
| 充電狀態 | 向喇叭專用通道查詢的結果與查詢時間 |
| 音量列 | 滑桿、−／+（±5%）、25／50／75%、靜音。右上角大數字是目前音量 |
| PartyCast | 目前狀態與「開啟／關閉」。按下後會等喇叭回覆確認，才更新畫面 |
| 曾一起 PartyCast | 這顆喇叭曾經確認過的 PartyCast 夥伴，上次讀到的電量、充電與韌體（**不是即時狀態**） |

更新頻率：

- 音量：每秒同步一次。在 Windows 或其他地方改了音量，這裡也會跟著變。
- 喇叭連線：每 5 秒偵測一次，新連上的喇叭會自動出現，斷線的會自動消失。
- 充電、韌體、PartyCast：每 15 秒查詢一次。**環繞或同步測試播放中會暫停查詢**，以減輕藍牙負擔。這段期間卡片保留上次的結果並標示讀取時間；按右上角「重新整理」可以立即讀一次。

注意事項：

- 卡片的音量是 **Windows 對那顆喇叭的音量**，和「系統預設輸出是不是這顆」無關。想讓一般的系統聲音從 Glow Mini 播放，請按左下角「音效設定」，選擇該喇叭。
- 只有已連線的立體聲音訊裝置會出現卡片。**TWS 配對時，每組只有連接電腦的主喇叭會出現**，副喇叭由主喇叭轉送，不會直接連電腦。
- 程式啟動時不會改音量、不會切換預設輸出，也不會自動開關 PartyCast。

### 通知區域與快捷鍵

- 「收至通知區域」會把視窗藏到右下角，程式繼續運作，環繞也會繼續播放。雙擊圖示可叫回視窗。
- 程式只會開一個。再次執行時，會把已開啟的視窗叫到前面。
- 視窗右上角的 × 會**直接結束程式**，正在播放的環繞也會停止。
- 通知區域右鍵選單：開啟視窗、全部喇叭音量 +5%／−5%、全部靜音／取消靜音、結束程式。滑鼠停在圖示上會顯示每顆喇叭的音量與電量。
- 視窗內快捷鍵：

  | 按鍵 | 作用 |
  |---|---|
  | `Ctrl + ↑` | 全部喇叭音量各 +5% |
  | `Ctrl + ↓` | 全部喇叭音量各 −5% |
  | `Ctrl + M` | 任一顆有聲音時全部靜音；全部靜音時全部取消靜音 |

### 用兩組 TWS 組成 4 聲道環繞

運作方式：

```text
電腦的聲音 ──► CABLE Input（設成 7.1，Windows 預設輸出）
                    │  Soundcore Desk 擷取這 8 個聲道
                    ▼
        ┌───────────┴────────────┐
   前方 TWS 主喇叭             後方 TWS 主喇叭
  （前左／前右 + 中央、重低音）  （後左／後右）
        │                        │
   前方 TWS 副喇叭             後方 TWS 副喇叭
```

#### 1. 準備兩組 TWS

每組兩顆 Glow Mini。兩顆都開機後，各長按藍牙鍵約 2 秒進入 TWS 配對。成功後：

- **主喇叭**（負責連電腦）：藍燈恆亮。
- **副喇叭**：白燈恆亮。

另一組照同樣方式配對。實際操作請以官方說明書為準。程式**無法**用軟體建立或解除 TWS，詳見 [TWS 研究記錄](research/TWS.md)。

#### 2. 把兩顆主喇叭都連上電腦

到 Windows「設定 → 藍牙與裝置」，配對並連線兩組的**主喇叭**。完成後，首頁會出現兩張卡片。

#### 3. 設定 CABLE Input

1. 先依[安裝 VB-CABLE](#安裝-vb-cable只有-4-聲道環繞需要)完成安裝。
2. 在程式的「4 聲道環繞」頁按「**聲音控制台 ↗**」，或按 `Win + R` 輸入 `mmsys.cpl`。
3. 在「播放」分頁選「**CABLE Input**」：
   - 按「**設定**」，選「**7.1 環繞**」（或 5.1），一路按「下一步」完成。
   - 按「**設為預設值**」。

這樣電腦所有的聲音都會先送進 CABLE Input，再由本程式分配到前後兩組喇叭。

#### 4. 開始環繞

1. 在程式左側點「**4 聲道環繞**」。
2. 「1 · 來源裝置」選 **CABLE Input**。下方應顯示「格式：48000 Hz · 8 聲道（7.1）」，而且沒有黃色警告。
3. 「2 · 前方與後方喇叭」分別選前方、後方那組的主喇叭。
4. 按「**▶ 開始環繞**」。左側的「4 聲道環繞」旁會出現「播放中」。

開始後可以切到其他頁面，或收到通知區域，環繞會繼續播放。按「■ 停止」或結束程式才會停止。程式會記住這次的來源與前後喇叭，下次自動選好。

#### 5. 確認聲道位置

- 程式內測試：按「3 · 聲道測試與音量表」的「前左／前右／後左／後右」，該聲道會響 3 聲「嗶」。也可以用這個確認每組 TWS 哪一顆是左、哪一顆是右。
- Windows 測試：在聲音控制台選 CABLE Input →「設定」→「測試」，或直接點圖中的單一喇叭。
  - 左前、右前、中央、超低音：應從**前方**那組出聲。
  - 左側、右側、左後、右後：應從**後方**那組出聲。

#### 6. 調整

「4 · 調整」區的設定會在開始環繞與結束程式時自動儲存：

| 設定 | 範圍 | 作用 |
|---|---|---|
| 前後延遲差 | −300～+300 ms | 對齊兩組喇叭的藍牙延遲。往右延後後方，往左延後前方。可先用[環繞同步測試](#環繞同步測試)找出數值 |
| 前方音量／後方音量 | 0～150% | 前後兩組在混音中的比例。和首頁卡片的喇叭音量是兩回事 |
| 一般立體聲內容時，後方播放 | 三選一 | 來源沒有環繞內容時，後方要播什麼（見下表） |
| 環繞延遲 | 0～40 ms，預設 15 | 只在「擴展環繞」時出現：後方的環境聲比前方晚多少 |
| 環繞強度 | 0～200%，預設 100 | 只在「擴展環繞」時出現：後方環境聲的大小 |

後方補聲的三種選擇：

| 選項 | 後方播放的內容 | 適合 |
|---|---|---|
| **擴展環繞**（建議） | 從前方分離出的左右差異：混響、空間感、寬廣的音色。人聲與主旋律留在前方 | 音樂，特別是現場錄音、混響多的曲子 |
| 複製前方 | 前方聲音的 80%，與前方同時播放。人聲也會從後方出來 | 想要四顆一樣大聲 |
| 不播放 | 沒有環繞內容時後方不出聲 | 只想聽真正的環繞聲道 |

- 來源有真正的 5.1／7.1 後方聲道時，三種選項都會直接播放原本的後方聲道。
- 後方安靜超過 1 秒才會開始補聲；真正的環繞聲道一出現，就立即切回。
- 看電影時，如果後方只想播原本的環繞聲道，選「不播放」。

**為什麼擴展環繞要讓後方晚一點？** 同一個聲音從兩個方向傳來、相差約 1～30 ms 時，人耳會把它定位在先到的方向（先到效應）。後方晚一點，人聲位置才會留在前方，後方只增加包圍感；超過 30～40 ms 就會開始聽得出回音。如果後方喇叭離你比前方近，可以把環繞延遲再調大一點（每近 1 公尺約早 3 ms 到達）。

#### 不用環繞時

Windows 預設輸出是 CABLE Input 的時候，**程式沒在跑環繞，電腦就不會有聲音**。不用環繞時，請按左下角「音效設定」，把預設輸出改回喇叭或耳機。

### 環繞同步測試

用來確認兩顆喇叭能不能對齊、會不會隨時間漂移。建議組環繞之前先測一次。

1. 讓兩顆喇叭**各自**用藍牙連電腦。先退出 TWS 和 PartyCast。
2. 左側點「**環繞同步測試**」，選喇叭 A（前方，高音滴答）與 B（後方，低音滴答）。
3. 按「▶ 開始播放」。兩顆會同時播放滴答聲，每 4 下有 1 下較大聲。
4. 調「對齊兩顆」的滑桿，直到高音和低音聽起來合成同一下：
   - 先聽到高音（A），往左拉。
   - 先聽到低音（B），往右拉。

   取消勾選「播放 A／播放 B」可以只聽其中一顆，確認聲音來自哪一顆。
5. 對齊後按「**記錄目前對齊值**」。之後每隔幾分鐘聽一次，不再對齊就重新調整並記錄。最後一筆和第一筆的差，就是兩顆喇叭之間的實際漂移；建議至少測 10～15 分鐘。畫面另外會顯示「Windows 端相對漂移」，那只是電腦送出端的量測值。

這個測試不會更改喇叭設定或系統預設輸出。

## 疑難排解

### 環繞沒有聲音

- Windows 預設輸出必須是 **CABLE Input**，見[設定 CABLE Input](#3-設定-cable-input)。
- 來源要選 **CABLE Input**，不是「CABLE In 16ch」。
- 來源格式若顯示「立體聲」，後方只能播補聲。請在聲音控制台把 CABLE Input 設成 7.1 或 5.1。
- 環繞頁的黃色提示會指出目前的問題。

### 聲音斷斷續續

先在「4 聲道環繞」頁，把滑鼠移到最下方的狀態文字上，看「缺資料」與「補靜音」：

- **兩者都是 0 或接近 0**：程式已把聲音完整送出，問題在藍牙傳輸這一段。一支藍牙接收器要同時送兩組立體聲，每組 TWS 的主喇叭還要再轉送給副喇叭，2.4 GHz 頻段很擁擠。
  - 用 USB 延長線把接收器移到桌面，讓它直接面對兩組喇叭；遠離藍色的 USB 3.0 孔、USB 3.0 隨身碟與集線器（USB 3.0 會干擾 2.4 GHz）。
  - 每組 TWS 的主、副喇叭擺近一點。
  - 單組測試：停止環繞，把 Windows 預設輸出改成其中一組喇叭直接播放。單組也會斷，主要是位置或干擾問題；單組不會斷，就是接收器撐不住兩組同時播放。
  - **檢查是否為仿冒接收器**：很多標示「CSR 5.0」的便宜接收器使用 CSR 的 USB 識別碼（`VID_0A12&PID_0001`），實際卻是其他廠牌晶片（例如 Barrot），在 Windows 只能用通用驅動程式，容易斷音甚至自行重啟。到「裝置管理員 → 藍牙 → 接收器 → 內容 → 進階」查看：製造商不是 Cambridge Silicon Radio，或韌體版本是 LMP 9（藍牙 5.0），就不是真正的 CSR8510（真品為 LMP 6，即藍牙 4.0）。建議換成 Realtek RTL8761B 系列（例如 TP-Link UB500、ASUS USB-BT500）或 Intel 的藍牙接收器。
  - Windows 同一時間只會使用一支藍牙接收器，所以無法插兩支分別負責兩組喇叭。
- **缺資料或補靜音持續增加**：電腦端來不及處理。關閉其他吃重的程式後再試。

### 環繞自己停了，顯示「環繞中斷」

某個裝置斷線了，最常見的原因是藍牙接收器自行重啟，兩組喇叭同時掉線。

1. 等喇叭重新連上，首頁卡片會重新出現。
2. 到「4 聲道環繞」頁按「↻ 重新整理」。
3. 確認來源與前後喇叭，按「▶ 開始環繞」。

接收器重啟後，Windows 可能替喇叭建立新的音訊裝置，名稱會改變（例如「2- soundcore Glow Mini」變成「3- …」）。若頁面提示「記住的前方／後方喇叭目前沒有連線」，請依藍牙位址末兩碼重新選擇前後喇叭。

### 喇叭沒有出現在首頁

- 確認喇叭已開機，而且在 Windows 藍牙設定中顯示「已連線」。
- TWS 的副喇叭不會出現，只有主喇叭會。
- 按右上角「↻ 重新整理」。

### 電量、充電或 PartyCast 顯示「未取得」

- 電量由 Windows 回報，剛連線時可能要等一下；數值可能以階梯變化，也有延遲。
- 充電與 PartyCast 需要喇叭回覆。喇叭忙碌或訊號不好時可能讀不到，稍後會自動重試。
- 環繞或同步測試播放中會暫停查詢，畫面顯示的是上次讀取的結果。
- 「未在充電」無法區分「沒插電」和「已充飽」，程式不會用電量 100% 推論已充飽。

### 再次開啟程式沒有出現新視窗

程式只允許開一個。它可能已經在通知區域，雙擊右下角的圖示即可叫出視窗。

## 技術說明

### 裝置辨識

- 用 Core Audio 列出播放裝置，依裝置狀態判斷是否可用。
- 用 Bluetooth API 取得喇叭名稱與藍牙位址，再透過 SetupAPI 的**裝置容器 GUID**，對應出「哪個音訊裝置屬於哪顆實體喇叭」。不會用名稱去猜，所以同名的喇叭也能正確區分。
- 電量讀取 Windows 藍牙服務的裝置屬性 `{104EA319-6EE2-4701-BD47-8DDBF425BBE5},2`，回報時間為同一 GUID 的屬性 7。這些不是公開的穩定 API，系統沒有提供時會顯示未取得。

### Glow Mini 專用協定

- RFCOMM 服務 UUID：`0cf12d31-fac3-4553-bd80-d6832e7b3136`
- 請求格式：`08 EE 00 00 00 <群組> <指令> <長度（LE）> [內容] <總和 & 0xFF>`；回應以 `09 FF 00 00 01` 開頭。
- 用到的指令：

  | 指令 | 用途 |
  |---|---|
  | `01 01` | 讀取狀態：充電旗標、韌體版本、序號、PartyCast 狀態，一次查詢取得 |
  | `01 A4` | 設定 PartyCast 開／關，喇叭回覆後再確認結果 |
  | `01 04` | 單獨查詢充電旗標（只用在診斷命令） |

- 只接受完整、總和檢查正確、旗標為 0／1 的回應；查詢有逾時限制，失敗時不沿用舊結果。
- 詳細記錄：[充電協定實測](research/README.md)、[PartyCast 實測](research/PARTYCAST.md)、[PartyCast 成員研究](research/PARTYCAST_MEMBERS.md)、[TWS 研究](research/TWS.md)、[保留配對測試](research/RETAINED_PAIR_TEST.md)。

### 4 聲道環繞的處理流程

1. 以 WASAPI loopback 擷取來源裝置（CABLE Input）的輸出。
2. 依 Windows 聲道遮罩拆成 4 路：
   - 前左／前右：加入中央 × 0.707、重低音 × 0.5。
   - 後左／後右：5.1 的後方或側邊聲道；7.1 的後方與側邊各 × 0.707。
3. 寫進同一條時間軸，前後兩組輸出從同一位置讀取，維持對齊。
   - 輸出比擷取晚 60 ms 讀取時間軸；偏差超過 40 ms 時重新對齊，狀態列的「對齊修正」會加 1。
4. 每組以 WASAPI 共用模式送到各自的主喇叭，取樣率交給 Windows 轉換（例如 48 kHz 轉成 44.1 kHz）。

### 擴展環繞

- 以短時傅立葉轉換分析：512 點、50% 重疊，48 kHz 時約 11 ms。
- 逐頻段追蹤左右聲道的 2×2 共變異矩陣，取較小的特徵值作為環境聲功率（主聲源與環境聲分離）。
- 以 Wiener 增益只把左右不同的成分送到後方。左右相同（置中）或只在單邊（硬聲像）的聲音視為直接聲，留在前方。
- 後方 6 kHz 以上逐漸淡出、9 kHz 以上不送，避免齒音跑到背後。
- 分析需要一個 FFT 框，這段時間前方與真正的後方聲道也一起等。所以開啟擴展環繞時，整體多約 11 ms 延遲，「環繞延遲」則是後方相對前方的精確差值。
- 實測：左右完全不同的聲音約有前方 55% 的能量進入後方；置中的人聲在後方低約 35 dB。

## 已知限制

- 不支援 EQ、燈光效果與韌體更新。
- PartyCast 無法取得即時成員清單，也不能切換 PartyCast 1.0／2.0。「曾一起 PartyCast」是過去確認時存下的紀錄，不是喇叭即時回報的資料。
- TWS 無法用軟體建立或解除。A3136 韌體 02.10 不回應官方 App 的 TWS 狀態查詢，詳見 [TWS 研究](research/TWS.md)。
- 只在韌體 02.10 上實測過。
- 環繞只有前、後兩組（各左右），沒有獨立的中央、側邊或上方喇叭；中央聲道由前方左右兩顆共同發聲。
- 兩組喇叭的藍牙延遲需要手動對齊。長時間播放的漂移只靠「偏差超過 40 ms 重新對齊」修正，沒有連續的自動校正。
- 環繞中斷後不會自動重新開始，需手動按「開始環繞」。
- 電量是 Windows 回報的數值，可能以階梯變化且有延遲；「未在充電」無法區分沒插電和已充飽。

## 移除

1. 在通知區域圖示按右鍵 →「結束程式」。
2. 刪除程式資料夾。
3. 刪除 `%LOCALAPPDATA%\SoundcoreDesk\`（設定與紀錄）。
4. 有安裝 VB-CABLE 的話：先在聲音設定把預設輸出改回喇叭或耳機，再以系統管理員身分執行 `VBCABLE_Setup_x64.exe`，按「Remove Driver」，然後重新開機。
